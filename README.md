# Disease Detection

## Project Overview

Disease Detection is a web application designed to identify and monitor plant diseases. This project helps users detect and track plant health issues using AI-powered image recognition.

## Getting Started

### Prerequisites

- Node.js (v16 or later)
- npm (v8 or later) or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/disease-detection.git
   cd disease-detection
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:8080](http://localhost:8080) to view it in your browser.
